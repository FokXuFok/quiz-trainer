# quiz-trainer · 题库刷题练习工具

一个通用的本地刷题练习桌面工具（Python + Tkinter，完全离线、无需联网）。**导入题库即可开刷**，支持顺序练习、随机练习、模拟考试、错题本、答题卡和做题进度持久化。

仓库自带一套示例题库：**NCRE（全国计算机等级考试）三级 · 数据库技术** 客观题题库（共 808 题，时效说明见下文）。

## 功能

- 顺序刷题 / 随机刷题 / 错题本复习
- 模拟考试（随机抽 40 题、百分制、120 分钟限时，交卷自动把错题加入错题本）
- 答题卡：答对绿色 / 答错红色 / 未答白色 / 当前题蓝色高亮
- 即时判定与解析：单选题点选即判，填空题提交后核对（答案做关键字匹配）
- 做题记录与错题**跨会话持久化**（progress.json / wrong.json，重开程序不丢）
- **导入自定义题库**：主界面点击【导入题库】选择 JSON 文件即可替换当前题库，旧题库自动备份为 `tiku.backup.json`

## 快速开始

**一键启动（推荐）**：仓库根目录已内置打包好的 Windows 单文件版 **[题库刷题练习.exe](题库刷题练习.exe)**，无需安装 Python，双击即可运行（约 10.8MB，首次启动会在程序同目录自动释放内置题库）。

源码运行（需要 Python 3.8+）：

```bash
python quiz_trainer.py
```

如果想要不带内置题库、自行打包，可执行：

```bash
pip install pyinstaller
pyinstaller -F -w --add-data "tiku.json;." quiz_trainer.py
```

> 提示：源码运行与 exe 运行行为一致——exe 首次启动时会自动从自身内置资源释放 `tiku.json` 到程序同目录，之后即可正常【导入题库】替换。

## 导入题库格式（JSON）

`tiku.json` 顶层为对象，包含 `total` 与 `questions` 数组；也兼容直接给定 `questions` 数组的文件。

```json
{
  "total": 3,
  "questions": [
    {
      "id": 1,
      "type": "single",
      "section": "第1章",
      "q": "数据库系统的核心是____。",
      "opts": ["数据库管理员", "数据库管理系统", "数据模型", "数据库"],
      "ans": "B",
      "analysis": "数据库管理系统（DBMS）是数据库系统的核心。"
    },
    {
      "id": 2,
      "type": "fill",
      "section": "第2章",
      "q": "SQL 中用于查询的关键字是____。",
      "ans": "SELECT",
      "analysis": "SELECT 语句用于数据查询。"
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 否 | 唯一题号，缺省时自动按顺序编号 |
| `type` | 是 | `"single"` 单选 或 `"fill"` 填空 |
| `q` | 是 | 题干文本 |
| `opts` | 单选必填 | 选项字符串数组，答案用 `A`/`B`/`C`/`D` 表示 |
| `ans` | 是 | 答案（单选填字母；填空填参考答案文本） |
| `analysis` | 否 | 答案解析，在主界面判题后展示 |
| `section` | 否 | 章节/来源，显示在题目右上角 |

> 导入时会校验格式，不合法的文件会被拒绝并提示具体错误；导入成功前，旧题库会自动备份为 `tiku.backup.json`，可随时手动改名恢复。

## 内置题库：NCRE 三级 · 数据库技术（时效说明）

随仓库分发的 `tiku.json` 为 **全国计算机等级考试（NCRE）三级 · 数据库技术**科目的客观题复习题库，共 **808 题**。其时效性与可靠性如下，使用前请务必阅读：

- **命题依据**：题目按 **2020 版（截至 2026-09 现行）三级数据库技术考试大纲** 的 14 章知识点整理。
- **真实试卷结构（供知悉）**：满分 100 分 = 选择题 40 分 + 填空题 30 分 + **设计与应用题 30 分**。本题库**仅覆盖前两类客观题**（单选/判断 651 题 + 填空 157 题），**不含设计与应用题（SQL、E-R 图、概念/逻辑设计等大题）**，大题部分的复习需另行准备；内置"模拟考试"为通用百分制抽题，不等同于真实试卷题型结构。
- **题目来源**：教育部教育考试院官方样题（53 题）+ 网络流传的历年真题汇编（86 题）+ 新版样题改版（3 题）+ 考生高频错题（12 题）+ 依据 2020 大纲生成的覆盖题（654 题）。
- **可靠性提醒**：NCRE 官方从不公布历年真题，真题汇编来自考生回忆与网络整理，个别题目可能存在表述偏差或答案争议；自动生成的题目主要用于知识点覆盖，难度与考点颗粒度与真题有差异。
- **时效风险**：题库内容锚定于 **2026-09 整理时点的 2020 版考纲**。一旦教育部教育考试院修订考试大纲、更新官方样题或调整题型分值，本题库（含个别已不考查的旧知识点题）可能过期失效。**参加考试前，请务必对照教育考试院发布的最新考试大纲核对考点，并将官方样题作为备考首选。**
- 本软件与内置题库均为 **非官方** 作品，与教育部教育考试院无关；内置题库素材版权归原作者/官方所有，仅供个人学习、非商业使用。

## 卸载 / 移除内置题库

删除 `tiku.json` 即可完全去除内置题库；工具本身与题库解耦，之后随时可通过【导入题库】使用自己的题库。
